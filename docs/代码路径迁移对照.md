## 职责拆分

- `enemyAI.ts` 集合入口 → `systems/enemies/enemyAI.ts`；实体 → `enemyEntity.ts`；契约 → `enemyTypes.ts`；Boss行为 → `systems/boss/bossBehavior.ts`。
- `LevelScene.tryCastSlot` → `systems/player/playerSkillExecutor.ts`；结算计算 → `systems/world/levelSettlement.ts`；场景保留副作用调度。
- `UiLayer` 存档与面板导航 → `ui/composables/useSaveActions.ts`、`useOverlayNavigation.ts`。
