# 营地美术与交互改造

日期：2026-10-27。依据：本次用户要求，以及 FR-10、FR-15、FR-13 规则 2、ARCH-17、UI-C1。

## 调整原因与范围

原营地只包含复用敌人纹理的商人、一个传送门图像和文字，三个区域外观相同。商人只能按交互键使用，传送门只能点击，缺少统一选择状态。

本次将营地呈现改为三个区域中的安全休憩地，设施仍调用现有商店、关卡选择和暂停流程。没有调整商品、价格、强化成本、伤害、运动、关卡解锁或存档格式；离开营地的写档仍由 `UiLayer.vue` 现有流程负责。

## 视觉与交互

| 营地 | 区域环境 | 营地近景 |
| --- | --- | --- |
| 林间余火 | 森林遗迹远景 | 近树枝叶、藤蔓、草丛、蘑菇、土质石路和暖色摊布 |
| 晶光驿站 | 地下水晶洞远景 | 晶簇、垂岩、浅池反光、蓝紫摊布和晶尘 |
| 云上栖所 | 天空神殿远景 | 断柱、金色接缝、神殿旗帜、石质地面和云海光屑 |

所有营地都有货物完整的木摊、独立绘制的兜帽商人、石框传送门、篝火、铺盖和行囊。火焰、火星、门内流光和区域光屑按固定数量更新。篝火是环境景物，没有假按钮或额外恢复规则。

营地专用资源行直接显示当前金币与成长技能点 SKP，不沿用上一关的关卡名、检查点、武器、战斗技能或 SP。进入营地和关闭面板时读取当前领域余额；营地活动期间仅在数值变化时更新文本，购买与强化后返回营地会立即显示新余额，不增加全局监听。

- 进入营地默认选中商人，直接按交互键（默认 E）即可交易。
- 左右方向键或 A/D 循环选择商人和传送门；移动键与交互键遵循现有按键重映射，提示同步更新。
- 交互键或 Enter 使用当前设施。选择传送门后可用键盘前往关卡选择。
- 鼠标悬停显示设施名称高亮、四角边框和操作提示；移出后恢复键盘选择。点击摊位或传送门直接使用目标。
- Esc 打开现有暂停面板。面板打开、场景淡出和场景停止期间禁止设施操作；面板关闭时清空旧按键，避免按住交互键再次打开。

## 实现边界

- `src/game/data/campPresentation.ts`：三个营地的调色及设施布局数据。
- `src/game/systems/campInteraction.ts`：不引入 Phaser 的设施选择、悬停和启用状态。
- `src/game/systems/campScenery.ts`：程序绘制近景。所有新增近景均由项目代码绘制；远景复用 `regionBackdrop.ts` 已登记的本地资源。
- `src/game/scenes/CampScene.ts`：场景组装、输入轮询与现有 UI 事件适配。设施命名为 `camp-merchant`、`camp-portal`，便于浏览器验证。
- `src/ui/i18n.ts`：仅新增 `camp` 文案组。

布局沿用 `centerDesignCamera` 保持 1024×768 最小逻辑视野内的构图居中；地面通过 `bindViewportLayout` 延展到扩展视口边缘。操作说明置于左下方，为现有右下角装备 HUD 留出空间。场景退出时清除 UI/设置监听、输入网关、设施监听和近景图形；区域远景由已有销毁接口自动清理。

4. 在商店中按 Esc 关闭，营地按 Esc 暂停并恢复，确认没有重复打开或残留输入。
5. 在 1024×768、宽屏和窄高窗口检查地面铺满、设施可见、标签及说明无重叠；购买物品和强化武器后返回营地，检查金币更新、SKP 显示正确。
6. 重复进入/离开营地及切换三个区域，确认无全局监听累积、图形残留或场景异常。

人工可用性、长期稳定性及跨浏览器验收仍需分别执行和记录。
