# Boss 技能差异化改造

日期：2026-10-28。用户已确认技能设计后实施；对应 FR-03/FR-04 的战斗行为、FR-07 的技能交互、DR-01 配置单一来源、DD-06 的三阶段循环和 K7 死亡优先规则。具体数值见《Boss技能差异化配置》。

## 玩法调整

| Boss | 独立招式及应对 | 阶段变化 |
| --- | --- | --- |
| 石像守卫者 | 裂地重锤在前方显示裂纹，跑出范围；地面震波沿地面向两侧移动，基础跳跃可躲；岩甲冲撞锁定方向，撞墙后收招 1.4 秒，可接近反击 | 第一阶段重锤与震波，后两阶段加入冲撞；冲撞前摇保留 0.8/0.7 秒 |
| 深渊蛛后 | 蛛网持续 5 秒，接触时移动速度为 65%，跳离恢复；蛛卵 HP18，可用 J 近战、K 弹丸和范围技能破坏，3 秒后孵化；吊顶俯袭升高 260px，预先锁定落点，落下 0.3 秒后造成短暂伤害，收招 1.2 秒 | 第一阶段蛛网与俯袭，后两阶段加入蛛卵；同时最多两片蛛网、两枚卵、三只孵化小蜘蛛 |
| 回响之影 | 标记换位先显示落点，换位本身无接触伤害，0.55 秒后才横斩；三段剑舞为两次横斩及慢速竖劈；延迟回响在原来的剑痕位置于 0.95 秒后重放，不追踪玩家 | 第一阶段换位与剑舞，后两阶段加入回响；最多一道待触发回响 |

所有招式均提供基础跑跳应对空间。三者血量保留 600/900/1400，接触伤害保留 5，玩家受击击退继续读取既有配置。阶段阈值及阶段保护时间保持原配置。蛛网与蛛卵的配置伤害字段沿用技能契约，网本身只减速，卵本身不造成伤害。

## 实现与生命周期

- `domain/bossAbilities.ts` 只维护游戏内时间、矩形范围、锁定位置、蛛网、蛛卵及动作轨迹，可在 Node 测试。施招时复制目标坐标，后续移动不改变已显示的落点与剑痕。
- `systems/bossAbilitySystem.ts` 连接真实 Arcade 身体、伤害、减速和孵化；`bossAbilityFx.ts` 使用同一快照绘制裂纹、震波、蛛丝、落点环与残影。复用已有角色帧和程序绘图，无新增外部素材。
- `EnemyAI` 继续驱动三阶段循环，动作持续时间来自技能配置。施招时受击保留攻击动画和时序，Boss 死亡仍立即进入死亡状态。守卫撞墙的当帧取消冲撞范围。
- 蛛卵接入 `CombatResolver` 的可破坏对象接口，同次挥击只命中一次，弹丸命中消耗，范围技能按真实圆形范围结算。范围技能先排队，敌方技能、弹丸与接触伤害结算后再执行；玩家本帧死亡时取消所有待执行玩家攻击，遵守 K7。
- 暂停冻结游戏内时间。阶段转换、玩家死亡/重试、Boss 死亡和切场景时清空技能、蛛卵、蛛网、召唤物及减速；恢复脚本位移中的 Boss 碰撞与透明度。场景退出时兼容 Phaser 已提前销毁物理 body 的顺序。
