# 技能、弹药装备、平台下跳与金币拾取修复

2026-10-27。用户要求逐项解决五个问题；飞镖经用户确认保留武器弹药规则。关联 FR-01 平台移动、FR-04/05 远程武器、FR-07 技能、FR-08 背包、FR-09 金币及 FR-14 HUD。

## 1. 技能中文名与介绍

原技能树直接显示去掉 sk_ 的内部 ID，title 只有 ID/费用/类别。现在 21 个技能配置带中文名，存档仍使用原 ID。鼠标悬停或键盘聚焦节点显示具体效果、伤害、范围、消耗、冷却及中文前置条件；数值介绍直接读取配置。被动明确说明无需绑定。

## 2. 技能点与 1–4 技能栏

技能点用于学习，不会自动成为技能。原界面未显示绑定槽位，equip 没有刷新树快照，释放空槽/SP 不足/冷却时也静默返回。

现在 Y 打开技能树，选择技能后点击学习；新学主动技能自动放入第一个空槽。上方显示 1–4，选槽后可绑定替换或清空，不会重复占槽；被动直接生效。HUD 显示中文技能名或待绑定。学习和绑定变更触发既有存档队列，刷新后保留。

同时修正执行问题：多重射击原先只认主手，初始轻弩在副手时消耗 SP 却不发射；现在主副手均可使用远程技能，没有远程武器时提前提示且不扣 SP。技能弹丸沿用原规则消耗 SP，不额外消耗普通弹药。冲刺原先速度被下一帧移动减速覆盖，且固定速度无法区分 180/240px；现在在既定 200ms 内按配置距离保持速度。生存被动的生命/SP 上限原先未接入；现在学习、读档和洗点按基础上限与被动合计重算，避免重复叠加。

## 3. 飞镖与箭矢

轻弩和火杖只消耗箭矢；飞镖枪消耗飞镖，有飞镖不等于已装备飞镖枪。飞镖枪按现有配置在第 2 区域营地以 240 金币出售。保留用户选择的规则，不增加直接投掷或弹药自动互换。

商店弹药行标明对应武器；背包点击弹药会说明当前是否装备、购买条件和使用键。购买武器后，在背包选中武器，使用新增的装主手/装副手按钮；装备到主手用 J/左键，副手用 K/右键，主手改键会同步到弹药提示。原右键/双击装备方式继续有效。

## 4. 单向平台下跳

原输入没有方向下动作，单向碰撞只判断下落与上一帧位置，没有主动下穿机制。现在 S 或 ↓ 与跳跃同时按下，可下穿正在支撑玩家的那一层单向平台。只忽略该层，不关闭整个碰撞体；更下方平台与实心地面继续碰撞。离开平台或超时恢复，传送/重生清理状态。普通跳跃、土狼时间和缓冲仍保留。

## 5. 金币悬浮拾取

原金币使用带重力的 Arcade 刚体，只与 collision 实心层注册碰撞，没有和 oneway 层碰撞，因而平台上的金币会落下。这不是渲染先后或地图晚加载造成的。

按用户提出的方向，改用无刚体显示对象。预置、敌人掉落和宝箱金币按原数量在生成点附近悬浮，96px 内仍以 300px/s 吸附，接触拾取；位移限制到目标，避免低帧率越过玩家，离开范围不残留速度。保留金币池、上限和危险区清理，不改金币收入或商品价格。
