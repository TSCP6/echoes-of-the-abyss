# 三大区域美术资源与接入

日期：2026-10-27。对应森林遗迹、地下水晶洞、天空神殿 12 关的环境改造；只改变呈现，不改变运动、碰撞或战斗规则。

## 视觉方向

| 区域 | 可行走地形 | 景深结构 | 四关色调 |
|---|---|---|---|
| 森林遗迹 | 浅草顶、露根岩土、带铆钉的木质单向平台 | 雾青树海、巨木枝冠、断裂石拱、垂藤及边缘蕨草 | 晨光林道、暮色古林、月雾遗迹、蚀月守望 |
| 地下水晶洞 | 冷青晶脉岩层、下垂晶体的薄岩台 | 深部洞腔、岩壁褶皱、钟乳石、蓝紫晶簇与矿尘 | 蓝晶裂隙、紫晶回廊、碧光深渊、蛛巢晶心 |
| 天空神殿 | 白色石砖、金色压边、金饰悬浮单向平台 | 环日及星座、远处悬浮殿群、破损柱廊、悬岛及云海 | 云海天阶、落日长廊、星环穹顶、终焉圣坛 |

背景的建筑、晶簇和树木均在玩法地形后方；神殿远中景额外降低透明度，亮度低于可站立的白金平台。每个区域包含天空、远景、中景、边缘框景和稀疏尘光；水平视差依次为 0.08、0.19、0.32。垂直视差限制在贴图余量内，不因高低差重复出第二层天空。

## 文件与接口

配置：`src/game/data/regionThemes.ts`。呈现：`src/game/systems/regionBackdrop.ts`。

```ts
// PreloaderScene.preload，在 load.setPath('assets') 之后：
registerRegionArt(this);

// LevelScene：第二参数为 LevelDef.sceneId；第三参数为 0~3 的关卡序号。
const background = createRegionBackdrop(this, 2, 1);

// LevelLoader：Tiled tileset 的名字继续是 terrain，只替换运行时纹理。
const theme = getRegionTheme(2);
map.addTilesetImage('terrain', theme.tileTextureKey);

// 提前离开自定义界面时可显式调用；场景 shutdown 也自动释放。
background.destroy();
```

`createRegionBackdrop` 自行监听视口尺寸与场景更新，抵消 Boss 镜头缩放。`destroy()` 幂等，移除 `resize`、`postupdate` 与 `shutdown` 监听并释放对象。营地可复用同一接口；无需创建物理体、额外计时器或 DOM 节点。

`variant` 默认为 0；有限数字截断后对 4 取模，负数也会稳定归一化，非有限数字回退 0。各关只改变天空图、背景调色与尘光，地形仍保持所属区域的统一材料。

运行时均位于 `public/assets/art/regions/`，无在线资源请求：

| 文件模式 | 数量 | 尺寸 | 用途 |
|---|---:|---|---|
| `{forest,cavern,temple}_tiles.png` | 3 | 704×352 | 32px 瓦片图集 |
| `{region}_sky_{0,1,2,3}.png` | 12 | 1536×1024 | 各关独立的不透明天空 |
| `{region}_{far,mid,near}.png` | 9 | 1536×1024 | 三层透明视差环境 |
| `{region}_motes.png` | 3 | 512×512 | 稀疏低亮度尘光 |

## Tiled 兼容约定

三份图集保留 22 列、11 行、242 图块，瓦片宽高均为 32，间距及边距为 0。Tiled 的 `terrain` 名称、地图内 GID 和碰撞属性不变。

重绘以下 0 基索引（括号内为地图 1 基 GID）：

- 顶面：6/7/8（7/8/9）。
- 中部：28/29/30（29/30/31），包括用户手工编辑的 1-1 实际使用项。
- 基岩：50/51/52（51/52/53）。
- 单向平台：40/41/42（41/42/43）。

其它 230 格从原 CC0 图集保留。顶面的实体像素从局部 y=0 开始；单向平台顶部也从 y=0 开始，薄平台下方保持透明。艺术图像不修改地图 JSON 内的 `solid` 属性，不以透明像素计算碰撞。

## 重建和验证

```powershell
python -X utf8 tools/prepare_region_art.py
npx.cmd --no-install vue-tsc --noEmit
```

脚本只依赖 Pillow，不访问网络，不改地图、其它角色资源或玩法配置；最后校验全部 27 张运行时 PNG 的尺寸。源包优先从 `tools/source-packs/` 读取；缺少 Pixel Adventure 原图时可回退到现有 `gen/terrain32.png`。森林树冠仍需要已归档 SunnyLand 源图。

开发比较图写入 `output/region-art/regions-preview.png`，不属于运行时预加载清单，也不应作为构建资源提交。

本分工已验证：资源重建成功、27 张 PNG 尺寸正确、天空 alpha 全部不透明、保留图块逐像素一致、12 个已用图块均非空，以及 `vue-tsc --noEmit` 通过。最终画面和实际高低差路线仍须在接入后的真实浏览器中检查；该项由整体关卡改造统一验证，不能以资源脚本代替试玩。
