# 第三章精英：回旋尾刃

2026-10-29，用户确认实现。对应 FR-03，补充第三章绿色鳄龙精英的独特表现；第一、二章精英维持原行为。

## 玩法契约

- 发现同高度（中心纵向差 ≤48px）、视线无遮挡的玩家后，进入190px内并落地时停步施法；检测距离仍为原200px。不主动追下平台。
- 前摇0.75秒：水平金色预警线、尾部聚光与进度提示，起手锁定朝向，不追踪改向。
- 尾刃速度360px/s，中心最远飞出260px后沿原路返回；去程绿色、返程橙色。攻击盒32×24px，伤害16，同次往返总共最多命中一次，沿用玩家无敌帧和K7结算顺序。
- 去程撞墙提前折返，回程撞墙立即回收，总飞行上限2.2秒。每帧以最多4px间距扫前沿与上下边界，并检查帧末端点。
- 回收后停步后摇1秒，蓝色脚下光圈提示可近身反击，期间无接触伤害；之后冷却3秒。前摇与飞行期间同样关闭本体接触伤害，避免叠伤。
- 同场多只精英共用起手闸，施法开始至少间隔1.15秒。
- 受击会打断并清除飞刃，进入完整后摇；死亡立即取消攻击表现和判定。死亡重试重置领域状态及起手闸。场景复用既有销毁路径，无新增计时器、监听器或独立弹丸对象。

原精英生命120、接触伤害5、移动速度90不变。美术复用绿色鳄龙与程序绘制特效，无新增外部素材。
