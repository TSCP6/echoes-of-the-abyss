# 敌人接触伤害与击退调整

日期：2026-10-27。用户要求降低敌人碰撞伤害到 5 点、缩短击退，并为第一个 Boss 冲刺增加判断时间。

## 调整依据与实现

- FR-04 接触伤害：四类普通敌人和三个 Boss 的 `contactDamage` 统一为 5。沿用现有伤害计算；5 点的 ±5% 波动取整后始终为 5。
- FR-04 玩家受击：`playerDefaults.knockbackPx` 从 120 降至 60；CombatResolver 删除重复常量，读取这一配置。沿用冲量倍率 3，水平初速度由 360 降至 180 px/s。该参数表示击退强度，实际位移随地面、空中与玩家输入变化，不能视为固定移动 60px。此共享受击路径也用于敌弹和危险区。
- FR-03 / DD-06 石像守卫者：三个阶段冲刺前摇由 0.6/0.5/0.4 秒改为 0.9/0.8/0.7 秒，每阶段增加 0.3 秒。预警效果读取同一攻击计时，前摇期间方向锁定、保持静止；冲刺距离、速度、持续时间和伤害沿用原配置。
- 受击无敌时间仍为 800ms；其他敌人和 Boss 技能伤害保持原配置。需求文档 FR-04、附录 A 与设计文档受击路径已同步。

## 本次验证

- 新增接触伤害/击退测试先在原实现上出现 9 项预期失败，修改后通过；新增三阶段冲刺时序测试先在原前摇上出现 3 项预期失败。
- 隔离 Chrome 执行 `tools/contact_damage.check.mjs`：左右接触均从 100 扣至 95，连续重叠不重复扣血，初速度为 ±180px/s，800ms 无敌；20 个真实渲染帧后地面无输入位移约 ±9.3px，速度归零。没有脚本或控制台错误。
- 隔离 Chrome 执行 `tools/guardian_charge.check.mjs`：实际三个阶段前摇 0.9/0.8/0.7 秒，帧采样到冲刺约 0.917/0.800/0.716 秒，期间水平速度为零；冲刺速度分别为 480/600/720px/s。没有脚本或控制台错误。
- 十二关地图可达性审计通过，0 违规。
- 全量 Vitest 31 个测试文件、228 项通过；`vue-tsc --noEmit` 和 `npm.cmd run build-nolog` 通过。浏览器脚本在独立测试浏览器运行，不使用用户游玩存档。

## 人工手感确认

在 1-1 主动碰触敌人，确认只掉 5 点血且更容易稳住位置；在 1-4 观察守卫者三个阶段的冲刺预警，确认新增判断时间是否符合预期。自动化时序与位移验证不能替代真人手感评价。
