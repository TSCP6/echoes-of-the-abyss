# 普通敌人行为差异化调整

日期：2026-10-28。依据：用户明确要求快速近战、慢速远程及有追踪和后摇的俯冲敌人。追溯 FR-03、FR-04、DR-01、AT-08～10；不重排既有编号。

## 原因与行为

两个地面怪原先主要靠接触伤害，差异不足；旧紫鹰只在开始俯冲时计算方向，缺少真实超时/超距退出，躲开后可能一直飞走，目标与自身重合还会出现除零速度。

| 稳定 ID | 新定位 | 参数 |
|---|---|---|
| enm_chaser | 蓝色负鼠，快速近战 | HP 45，移速160，侦测220；60px内前摇0.3s，扑击240px/s持续0.18s，主动伤害12；后摇0.55s，随后冷却0.65s |
| enm_patrol | 红蚁，慢速远程 | HP30，移速60，侦测300；140～280px停步瞄准0.6s，单发伤害10、弹速230、射程480；后摇0.5s，随后冷却1.5s；近身最多退让72px |
| enm_flyer | 紫鹰，追踪俯冲 | HP25，侦测300；巡航上限50，追踪110，寻找玩家上方110px的位置；220px内且高于目标40px开始前摇0.65s，末0.18s锁定；俯冲300px/s、伤害14，最长0.85s/260px，撞墙或越过目标也结束；低空后摇1s，随后冷却1.2s并升空重整 |

HP、掉落、体积、基础接触伤害5沿用原配置。前摇、主动攻击、后摇关闭接触伤害，主动攻击一轮只结算一次；其余阶段仍有接触伤害。冷却从完整后摇结束后计时。受击中断施招，取消未发射攻击；玩家死亡不再开始攻击。

地面所有移动含扑击、退让均使用本帧实际刚体脚底与前向地形探测，不主动跨悬崖或撞墙。短暂遮挡只追踪最后可见位置，丢失2.5s后归巢；追击/紫鹰活动距离上限500px，远程420px。归巢期间不重新被玩家拉走。紫鹰保留实体瓦片碰撞，当前使用局部直线追踪，不具备复杂迷宫寻路。

## 实现与边界

- 配置：`src/game/data/enemies.ts`、`normalEnemyCombat.ts`。ConfigRegistry检查必需配置、引用、有限正数、时间和距离关系。
- 规则：`src/game/domain/normalEnemyBrain.ts`，无 Phaser / Vue / DOM 运行时依赖。
- 物理桥接：`systems/enemyAI.ts` 用实际双方刚体中心，按速度与dt做悬崖探测；实体重置时创建干净状态机，冻结时停止速度并挂起计时。
- 战斗：`systems/combatResolver.ts` 在玩家攻击前处理普通敌人主动伤害，复用无敌帧和K7死亡优先；读取本帧刚体位置更新攻击盒。
- 预警：`systems/normalEnemyFx.ts` 使用同一状态快照，黄色为前摇、橙红为主动攻击范围、浅蓝为可反击后摇；每场景仅一个Graphics，无新增监听或计时器。
- 美术：复用当前动画、弹丸纹理及共享死亡消散，没有新增素材，也没有变更许可。可选独立动作见《普通敌人攻击动画提示词》。精英、特殊Boss召唤物使用原分支，Boss改造为工作区中独立工作。
- 本次不改地图、不运行地图生成器、不改玩家运动参数，不涉及存档迁移。

## 验证

- 测试先复现旧地面接触AI、悬崖追击、紫鹰无超时及位置重合的失败，再实现并验证；额外覆盖锁定方向、超距/撞墙/越过目标收招、受击取消、玩家死亡、有限退让、短暂遮挡记忆与攻击消费。
- 隔离Chrome检查脚本：`tools/normal_enemy_combat.check.mjs`，导出 `checkNormalEnemyCombat(chromium, options)`；由本机已有Playwright运行，不增加运行时依赖。Vite须用`npm.cmd run dev-nolog -- --port 8101`启动；脚本默认地址`http://localhost:8101`，可传`url`覆盖。
- 浏览器25项通过、控制台错误0。使用真实1-1/1-2地图、Phaser/Arcade完整管线与固定60Hz步进，隔离存储；测试夹具放置角色并召唤指定小怪，部分案例通过真实键盘移动；不将夹具验证称作完整人工通关。
- 截图与JSON结果在忽略目录`output/normal-enemy-ai/`，不提交。本次独立副本（fcf4c56 基线加本任务改动）336项单元测试、vue-tsc类型检查与build-nolog生产构建通过；同一独立副本的25项浏览器检查也全部通过，结果在`output/normal-enemy-ai/isolated-browser/`。工作区同时进行Boss改造，未夹带进本任务提交。

人工试玩仍需确认：近战前摇是否足以反应；红蚁射击间隔与混编压力；紫鹰低空后摇是否容易接近、狭窄多层地形是否卡住；建议在1-2体验地面怪，在2-3体验紫鹰。自动化不能替代真人手感或长期跨浏览器验收。
