# 蛛后与回响之影：美术及技能反馈

2026-10-27。沿用 `EnemyVisual` / `BossDangerFx` 管线，为 2-4、3-4 导入独立动画；素材作者、用途和重建命令见《素材许可清单》。

- 深渊蛛后：独立待机、移动、施法、受击、转阶段和死亡动作；绿色毒液弹、按真实伤害矩形绘制的毒网、孵化光环与幼蛛。蛛后脚底吸附到下方地面；幼蛛使用较小的独立帧网格。
- 回响之影：使用 Kronovi 的 Undead Executioner，接入待机、施法、挥镰、冲刺、阶段及消散动作。紫色灵魂弹、三张复用的冲刺残影、召唤光环与独立灵体出场/待机/死亡动画；背景光晕让深色披风保持可辨。
- 三个 Boss 阶段切换均显示护盾和中文反馈；HUD 显示角色名称。视觉动画不控制伤害时序，不改变 HP、伤害、射速或攻击循环配置。
- `bossSkillPresentation.ts` 提供预警与实际弹幕共用的角度，以及召唤预览和生成共用的坐标。四个召唤物不再重叠在两个点上。
- 召唤物接入地形碰撞；重试销毁召唤物及其碰撞器，并清空光环、残影、地面危险区、弹丸，防止掉穿地图或越重试越多。
- 美术预处理跳过源图空白格，保留脚底基线；蛛后原包使用不规则列间距，不能按等宽网格直接切帧。全量 alpha 校验覆盖 163 帧。
