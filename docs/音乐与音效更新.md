# 音乐与音效更新（2026-10-29）

用户反馈原背景音乐不好听且嘈杂，并明确选择“柔和钢琴与环境氛围”。本次落实 FR-16 的场景配乐、动作反馈、三路音量及交叉淡化；保持伤害、冷却、判定、技能数量与存档音量偏好。

## 配乐与场景

原配乐来自短促 Music Jingles，持续循环会频繁重复起音。本次移除五组旧 BGM，改用四首经独立核实 CC0 的长曲。

| 使用位置 | 配乐 / 作者 | 处理后时长 | 本地文件前缀 |
|---|---|---|---|
| 菜单、三个安全营地 | First Light Particles / Yoiyami | 128.72 秒 | bgm_menu_piano |
| 第一章探索、Boss 入场前 | Exploration Theme / Cleyton Kauffman | 134.40 秒 | bgm_exploration |
| 第二、三章探索、Boss 入场前 | Mystical Piano / Indieteur | 95.00 秒 | bgm_ruins_piano |
| 三个 Boss 交战中 | Pursuit / Sudocolon | 73.90 秒 | bgm_boss_piano |

菜单原曲使用三秒首尾交叠连接；Exploration Theme 使用作者原生循环；Mystical Piano 按作者说明取 1:35 循环点。Boss 采用钢琴独奏以保留节奏感，并避免强打击乐覆盖战斗反馈。换阶段只把强度从 0.82 调为 0.90/1.00，不切曲或重播开头。死亡重试、Boss 击败后恢复区域音乐。

四曲统一两遍 EBU R128 响度处理，目标 -22 LUFS / -3 dBTP，削弱极低频与尖锐高频。音乐通道额外乘 0.70 混音系数；用户原有主音量、音乐、音效设置继续生效，未强行覆盖存档中的音量。

## 音效

发布 32 组音效，其中保留并柔化 15 个已登记 Kenney 音效，另有 17 个项目原创合成音效。

- 六把武器：短剑清晰轻挥、双匕首双短切、巨斧低沉宽挥、轻弩弦响、飞镖枪短喷、火杖柔和火焰呼声。
- 九个主动技能：旋风斩、刃影连击、刃影风暴分别采用旋流/三连/多段音色；多重射击、回响齐射、箭雨采用不同音阶与节奏；冲刺、治疗、闪移各自区分。
- 金币改为短提示，死亡改为柔和下降音，治疗为上行和弦，通用技能移除原 glitch 声。跳跃、落地、命中、检查点、道具、购买、通关和 UI 延续原事件触发位置。
- 每个音效单独分配增益，UI/金币/落地较轻，受伤与重要反馈更清楚。音效峰值预处理约 -5 dBFS，再乘各自增益与用户音量。
- 仅在攻击/施放成功后触发。技能齐射共享一次技能声，不逐弹叠加武器声；空仓与冷却只播放轻量错误提示。

## 播放修复

1. 修复原 `tick(dt 秒)` 与 `MERGE_MS=50` 混用，之前会把 50 毫秒去重变为约 50 秒；现统一使用毫秒时钟。
2. 淡化改由唯一的游戏全局 STEP 推进，移除 LevelScene 的重复调用。菜单、营地及暂停面板不会让淡化停住。
3. 连续切曲会重新定向当前淡化并销毁更早声道，不累积淡入/淡出任务。稳定时只有一个循环音乐实例。
4. 最多八路一次性音效，同类最多两路；重要反馈可替换最早音效。播放完成即销毁，detach 释放音效、音乐、订阅与待播请求。
5. 实时音量应用到淡入曲、淡出曲和仍在播放的音效，静音不会在下一帧淡化时回弹。
6. 手势解锁只保留最新场景 BGM；动作反馈队列最多三个，仅补播 120ms 内请求，避免进入游戏时旧动作声集中响起。

清单唯一来源是 `src/game/data/audioCatalog.ts`，预加载和十二关 BGM 元数据已同步。`audioAdapter` 的浏览器手势解锁、失焦暂停/恢复继续保留。

## 资源与复现

全部运行时文件均为随包发布的本地 `.ogg` / `.m4a`。处理脚本只在显式重建时联网，游戏运行不调用第三方服务。逐曲来源与许可见 `docs/素材许可清单.md`；`public/assets/audio/audio-manifest.json` 记录源文件哈希、发布文件哈希、时长、峰值与 RMS。

```powershell
# 需要 Python numpy 与 FFmpeg，可用 --ffmpeg 指定；也支持现有 imageio_ffmpeg。
python -X utf8 tools/prepare_game_audio.py --download
# 只校验已有 72 个音频文件，不重新生成、不联网。
python -X utf8 tools/prepare_game_audio.py --check
```

原始下载和中间 WAV 仅保存在已忽略的 `output/audio-source/`，不加入发布资源或 Git。
