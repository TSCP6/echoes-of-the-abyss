# 敌人美术试点与战斗可读性修复

日期：2026-10-27。试点范围：巡逻敌人、1-4 石像守卫者；三个 Boss 共用的攻击预警和危险区结算同时修正。

## 问题与修复

- 普通敌人闪烁：切帧脚本漏加横向帧偏移，8 帧重叠在第一格，另外 7 格透明。改为独立拼接，并添加逐格 alpha 检查。蚂蚁采用 NEAREST ×2，与主角像素比例一致；96×96 网格、6 FPS、完整循环约 1.33 秒，停止时使用固定待机帧。按朝左源图修正翻转方向；躯干受击范围为 40×36，脚底基线不变。
- Boss 关卡有血量也死亡：旧代码在危险区普通命中后无条件设置死亡标记。现在普通危险区经 CombatResolver 结算，使用伤害、受击保护、音效、击退及真正致死判定；地图即死区仍独立处理。
- Boss 从远处偷袭：以前进入关卡就循环放技能。现在进入侦测范围才开战并锁定场地。
- 冲撞不明显：旧代码冲撞速度下一帧就被缓步移动覆盖。现在使用蓄力、出招、收招三个阶段，持续冲刺 0.5 秒，方向在蓄力时锁定。显示方向箭头、范围、蓄力进度与收招提示。
- 弹幕和地刺难辨认：弹幕显示扇形轨迹并使用独立发光危险弹；地刺落在地面、先显示 0.85 秒黄色预警，再转为橙红色伤害区。渲染和判定使用相同矩形，技能伤害取配置值。
- 重生：清空旧地刺、弹幕及未执行攻击，重置 Boss 开战状态、技能计时和动画。

## 美术来源与边界

巡逻兵使用本地 SunnyLand Woods 的 8 帧蚂蚁动画；石像使用 Kronovi Mecha-Stone Golem 的待机、发光、射击、防御受击、近战和 14 帧崩解，共 50 帧。许可与重建命令见《素材许可清单》。原始 Boss ZIP 和 Aseprite 工程不作为素材包分发。

后续已接入蛛后、回响之影及其召唤物的独立美术，见《其余Boss美术与技能可视化》。其余普通敌人保留原有呈现。

## 验证

- `python tools/check_enemy_art.py`：所有 58 帧均有实体像素，尺寸和帧数匹配。
- `npx vitest run --maxWorkers=1 --minWorkers=1`：20 个测试文件、167 项测试。
- `npx vue-tsc --noEmit`、`npm run build-nolog`：类型与生产构建检查。
- Playwright MCP 加载 `tools/enemy_art.check.mjs`：23 项浏览器检查，覆盖三个 Boss 关卡的危险区预警、非致死受伤、受击保护，以及石像攻击、阶段切换、崩解、重生。
- 原有 `tools/boss_goal.check.mjs`：11 项通关与重试回归检查。
- 两组浏览器检查均使用独立无头 Chrome，不修改玩家的本地存档。脚本默认测试地址为 `http://127.0.0.1:8093`，可通过参数调整。
