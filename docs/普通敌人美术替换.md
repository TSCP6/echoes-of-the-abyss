# 普通敌人美术替换

日期：2026-10-28。关联 FR-03 敌人行为、FR-16 表现反馈、NFR-09 素材许可。

## 修改范围

| 敌人 | 本次外观 | 动画 |
|---|---|---|
| `enm_chaser` 追击型 | 蓝色负鼠 | 6 帧移动、固定待机、受击反馈、死亡消散 |
| `enm_flyer` 飞行型 | 紫色鹰 | 4 帧振翅、受击反馈、死亡消散；贴图朝向随真实水平速度更新 |
| `enm_elite` 精英怪 | 绿色鳄龙 | 4 帧待机/移动，较大轮廓、受击反馈、死亡消散 |

复用 `EnemyVisual` 的状态优先级、加载和动画注册流程。新资源的原始朝向均朝左，通过 `facesLeft` 统一处理翻转；死亡片段由 `deathKey` 显式指定，共用 6 帧消散。受击片段采用原图定帧，配合现有 CombatResolver 的闪白与硬直，未伪称素材自带专用受击动画。

新增美术配置集中在 `src/game/systems/normalEnemyArt.ts`，没有修改 `src/game/data/enemies.ts`、技能规则、伤害、生命、速度、掉落、冷却或关卡 JSON。继续使用 28×34、28×24、40×48 的原碰撞体；128px 贴图通过留白和脚底对齐适配原有偏移公式。翅膀、尾部等装饰不扩大受击范围。

## 素材与复现

负鼠、鹰和消散来自 Ansimuz 官方发布的 Sunny Land CC0 美术；鳄龙复用已归档的 SunnyLand Woods 美术。来源、原始文件和许可逐项登记在《素材许可清单》。运行时新增 4 张 PNG、20 帧，不新增外部服务依赖。

从作者 OpenGameArt 页面下载 `sunny-land-files.zip` 后运行：

```powershell
python -X utf8 tools/prepare_normal_enemy_art.py <sunny-land-files.zip>
python -X utf8 tools/check_enemy_art.py
```

脚本逐格写入并检查透明通道，避免之前将所有动作覆盖在第一格造成的闪烁。

## 人工试玩

刷新游戏后，在 1-2 查看负鼠和紫鹰，1-3 查看精英鳄龙；左右靠近并攻击，确认角色持续可见、朝向与移动一致，死亡时完成消散。可在三区域继续观察对背景的辨识度。长期稳定性、跨浏览器以及玩家主观动画观感仍需单独人工验收，本轮 Chrome 自动化结果不代替这些项目。
