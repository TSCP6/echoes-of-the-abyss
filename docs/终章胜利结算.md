# 终章胜利结算

2026-10-29，用户确认“深渊散尽，重见晨光”方案后实施。本调整扩展 FR-15 结算交互、FR-19 成绩展示及 FR-13 存档规则，普通关卡保持原有结算。

## 触发与安全结算

- 前十一关均已完成，最终关配置的 Boss 被真实击败后，自动完成最终关，无需继续走到出口。
- 同帧规则继续遵守 CombatResolver 的敌方先结算原则；玩家已经死亡时不会触发终章。最终击杀成立后，设置安全保护，清除弹丸、危险区域、专属 Boss 技能与召唤物，并停止后续玩法管线。
- 场景结算增加一次性守卫，避免同帧终点、重复回调导致通关次数、首通奖励和记录重复提交。再次进入关卡会重置守卫。
- 最终 Boss 金币按现有重玩倍率直接入账，固定材料和原掉落表保持不变。随机物品先尝试入包；满包余量写入 `progress.victoryLoot`。结局可打开背包、返回后领取，或稍后通过主菜单重看结局再领。
- 沿用双键本地保存、校验和及失败提示；新增可选字段缺失时按空数组恢复，旧 v1 存档继续可用。重看结局不会重掷掉落或发放奖励。

## 画面与交互

- 专属原创 SVG 像素全景串联森林、晶体洞窟和天空神殿；显示现有玩家贴图及当前武器的像素造型。
- 首次通关演出约 3.2 秒，再次通关约 1.1 秒；“跳过演出”或 Esc 可直接展开结算。系统偏好减少动态效果时直接显示。计时器和键盘监听随组件卸载清理。
- 展示三张区域纪念卡：该章完成关卡数、回响碎片及 Boss 击败状态。普通通关显示“破晓行者”，有效 36 枚碎片全部收集后显示“完整回响”。不引入额外战斗奖励或评分。
- 首页统计：完成关卡、回响碎片、已开启宝箱、累计游玩时长。详细记录包含累计击杀/死亡、剩余金币、最终关最佳用时、本次最终关用时和当前装备。
- 明确标注“本存档累计 · 包含重试与重玩”，累计时长不会冒充一次连续流程的速通成绩。主菜单重看时不展示过期的“本次最终关”数据。
- 提供返回第三章营地、重访关卡、返回标题。完成全部关卡的存档在主菜单出现“重看结局”，刷新和旧通关档均可使用。Esc 不会把终章关闭成空白菜单。
- 1024×768 使用较短全景以露出主要导航；宽屏有完整全景，小窗口纵向滚动。保留键盘焦点及中文无障碍名称。

## 实现入口

- `src/game/domain/campaignVictory.ts`：配置驱动的只读统计、通关前提、暂存物品领取。
- `src/game/scenes/LevelScene.ts`：最终击杀桥接、安全保护、幂等结算。
- `src/ui/VictoryView.vue`、`VictoryWeapon.vue`：演出、全景、纪念卡与交互。
- `src/ui/UiLayer.vue`：终章状态、主菜单重看和背包返回。
- `public/assets/art/victory/dawn.svg`：本项目原创矢量场景，不需要网络服务。
