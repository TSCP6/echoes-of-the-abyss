# Boss 远程应对与抗性实现计划

> 执行方式：按已确认方案分段实现，以测试失败、实现、验证闭环推进；独立工作使用 high 子智能体。

**目标：** 远程流派保留通关能力，站桩、单向后退和高台射击不能绕过 Boss 的决策与招式。

**设计依据：** 用户已确认本轮对话中的开战保护、距离决策、守卫举盾推进、蛛后区域压迫和平台俯袭、影子有效换位，以及随后确认的武器抗性表。

**技术与边界：** Phaser 4 / Vue 3 / TypeScript / Vitest；纯前端离线运行，保留存档、玩家运动、Boss HP、接触伤害及已有地图手工修改。配置集中在 data；领域规则不依赖 Phaser。

- [x] 配置与领域规则：守卫轻弩/飞镖×0.7、巨斧×1.1，撞墙硬直取消减伤；蛛后轻弩/飞镖×0.9、火杖×1.15；影子全部远程×0.85。其余为1。配置校验覆盖非法倍率与未知引用。
- [x] 开战与决策：身体进入战场即激活；战场外与未开战不受伤且有可见保护。守卫远距举盾推进，出招和收招开盾；近战招式先接近再释放。蛛后远距优先区域压迫，影子远距优先换位，落点进入真实横斩范围。
- [x] 技能几何：蛛网/蛛卵/俯袭锁定玩家所在可站立表面；孵化物能追击，平台射击不形成永久安全区；预警与伤害仍共用快照。影子保留明确标记与0.55秒出手延迟。
- [x] 伤害整合：普通攻击、弹丸与技能记录施放时武器来源/等级，统一应用倍率；守卫正面举盾拦弹，避免叠加减伤。显示抗性、开盾与破甲提示。
- [x] 浏览器验证：隔离存档、原始 Phaser 实例、真实弹药和非无敌玩家，三Boss分别执行原地射击、后退射击、高台射击、主动走位射击与近战；记录实际扣血、弹药、击杀和失败，不能用无敌或直接改Boss HP替代正常打法。
- [x] 验证交付：相关单测、全套单测、类型检查、生产构建、技能与生命周期回归、独立代码复审；记录真人难度与跨浏览器缺口；只提交本任务变更，不推送。
