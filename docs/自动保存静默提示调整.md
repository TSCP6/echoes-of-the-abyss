# 自动保存静默提示调整

2026-10-28，关联 FR-13 存档、FR-14 界面反馈。

原 UiLayer 对每次 save:written 都显示四秒“进度已保存”，并重置计时。金币和弹药变化会频繁触发保存，因此提示持续遮挡视野。

现在自动保存只更新存档摘要和状态，不显示成功弹窗；保存失败仍保留醒目的失败提醒、重试与导出入口。后续自动写入恢复成功时清除失败提示。用户手动重试、保存并退出或导入成功仍显示短暂确认，自动保存不会延长确认时间。未修改存档触发点、400ms 合并窗口、数据格式或持久化流程。

验证：tools/save_notice.check.mjs 在隔离 Chrome 中，修改前 4/8，修改后 8/8，覆盖真实金币变化、射击弹药消耗、存储配额失败、自动恢复、手动重试、成功提示计时和保存退出。存档单测 17/17，vue-tsc 和生产构建通过。浏览器测试仅修改隔离上下文中的 Storage，不影响用户存档。
