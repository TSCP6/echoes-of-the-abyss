# 关卡选择紧凑节点调整（2026-10-29）

用户指出选关按钮太大、显得突兀，并授权制作一版设计。此次保留三章总览和既有选关流程，围绕 UI-02、FR-12、AT-41 调整尺寸和视觉层次。

- 桌面关卡按钮由实测约 191×72 改为 64×48，章节内容最大宽度由 800 改为 440；节点路线最大宽度 352。窄窗口仍保留至少 44px 宽的点击区域和每章四节点同排。
- 使用细线连接关卡，边框减为 1px。森林、洞窟、神殿分别复用 accent、sp、gold 令牌标记章节；第四关增加装饰菱形，通关保留勾选徽记。
- 未解锁节点保留关卡编号，使用小锁和虚线区分；继续使用原有 disabled 与 aria-label。鼠标悬停、键盘 focus-visible 和营地/返回命令保持可用。

- 删除 UiLayer 中会把窄屏节点重新撑到 64px 高的旧覆盖，让组件统一管理尺寸。

没有新增美术资源、外部依赖或存档结构调整。解锁顺序、关卡状态、重玩数据与进入场景的命令均沿用现有领域服务。
