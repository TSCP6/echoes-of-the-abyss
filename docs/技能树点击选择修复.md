# 技能树点击选择修复

2026-10-28，关联 FR-07 技能学习与装备。

原先 mouseenter/focus/click 都会更换 selectedId，鼠标前往学习按钮或快捷槽途中可能改变操作目标。现在仅点击节点更换选择；鼠标移动、离开和单纯键盘聚焦均保留上次选择。移除原生悬停 title，使用 aria-pressed 标记选择，说明文案改为点击操作。Enter/Space 激活原生按钮仍可选择。

验证：原浏览器检查新增两项用例均复现失败；修改后用真实 Vue 组件独立挂载进行 7 项浏览器回归，全部通过，覆盖悬停/聚焦保持、学习原技能、绑定原技能及点击切换；无脚本异常。vue-tsc 与生产构建通过。
